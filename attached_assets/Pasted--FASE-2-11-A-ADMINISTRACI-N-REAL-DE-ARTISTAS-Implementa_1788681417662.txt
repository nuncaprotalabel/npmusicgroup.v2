# 4. SEGURIDAD

El acceso debe estar protegido server-side mediante el RBAC existente.

No depender solamente de ocultar elementos en React.

Validar:

* sesión
* usuario activo
* permiso correspondiente

Un usuario sin sesión debe recibir `401` cuando corresponda.

Un usuario autenticado sin autorización debe recibir `403`.

Al consultar un artista, el servidor debe validar que el artista exista y resolver sus relaciones mediante PostgreSQL.

No confiar en datos enviados por el frontend como prueba de autorización.
