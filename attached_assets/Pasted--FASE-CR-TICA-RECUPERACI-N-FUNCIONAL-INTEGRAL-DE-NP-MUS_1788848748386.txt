# FASE CRÍTICA — RECUPERACIÓN FUNCIONAL INTEGRAL DE NP MUSIC GROUP

## 0. CONTEXTO

Estamos desarrollando **NP Music Group**, una plataforma privada de gestión y operación musical.

El proyecto actualmente tiene una interfaz bastante desarrollada visualmente, pero presenta un problema crítico:

> Muchas funciones existen solamente a nivel visual y no están conectadas correctamente con backend, base de datos, autenticación, autorización, navegación o lógica de negocio.

Por lo tanto, **NO debemos continuar agregando nuevas funcionalidades ni hacer otra fase de diseño hasta conseguir que el sistema existente sea realmente funcional de extremo a extremo.**

Esta fase tiene prioridad absoluta.

---

# 1. OBJETIVO PRINCIPAL

Convertir el proyecto actual de NP Music Group de una interfaz principalmente visual en una **plataforma funcional de extremo a extremo**.

Cada módulo existente debe:

1. Tener una ruta real.
2. Tener navegación real.
3. Tener permisos correctos.
4. Tener conexión real con la base de datos.
5. Tener operaciones CRUD cuando correspondan.
6. Tener estados reales.
7. Tener validaciones.
8. Tener manejo de errores.
9. Tener persistencia.
10. Actualizar correctamente la interfaz después de las acciones.
11. Poder volver al dashboard/home correspondiente sin cerrar sesión.
12. Respetar el sistema de roles existente.
13. Funcionar tanto en desktop como en móvil.

---

# 2. REGLA MÁS IMPORTANTE

## NO CREAR FALSAS FUNCIONALIDADES

No quiero:

* botones decorativos;
* formularios que no guardan nada;
* estadísticas falsas;
* tablas con datos hardcodeados;
* páginas que solamente muestran "próximamente";
* acciones que parecen funcionar pero no modifican la base de datos;
* rutas que redirigen al inicio sin razón;
* permisos simulados;
* componentes desconectados del backend;
* datos mock utilizados como sustituto de datos reales;
* estados falsos para hacer parecer que una operación terminó correctamente.

Si una función existe en la interfaz, debe funcionar realmente.

Si todavía no puede funcionar por una dependencia técnica, **detén esa parte, identifica exactamente la dependencia faltante y corrígela**, en lugar de simularla.
