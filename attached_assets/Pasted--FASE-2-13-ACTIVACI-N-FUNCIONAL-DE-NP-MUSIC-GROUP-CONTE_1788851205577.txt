# 1. REGLA FUNDAMENTAL

Un módulo solamente puede considerarse funcional cuando existe este flujo:

```text
INTERFAZ
   ↓
VALIDACIÓN
   ↓
API / SERVER ACTION
   ↓
AUTORIZACIÓN SERVER-SIDE
   ↓
POSTGRESQL / SERVICIO REAL
   ↓
RESPUESTA
   ↓
ACTUALIZACIÓN DE UI
```

Si falta cualquiera de estas capas, el módulo sigue siendo parcial.
